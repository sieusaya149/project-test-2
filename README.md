# zalo-clone

A Zalo-like messenger: phone-number accounts, friends, realtime 1-1 and group chat, receipts and images.

Work is tracked in Jira project **ZALO** (https://huninna.atlassian.net/jira/software/projects/ZALO).
Branches and commits reference the Jira key, e.g. `ZALO-2`.

## Run

```sh
npm start          # http://localhost:3000/health
```
